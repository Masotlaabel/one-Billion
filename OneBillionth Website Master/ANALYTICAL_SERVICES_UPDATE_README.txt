  from the website. Any selected supporting document must be attached manually.

  1. Back up your existing Git working folder.
  2. Copy the files inside this ZIP into the existing Git repository folder.
     DO NOT delete your existing .git or .vercel metadata directories.

      git status
      git add index.html home.css analytical-services assets/analytical
      git commit -m "Add analytical and laboratory services page"
      git push origin main
  4. Check the existing Vercel deployment for the updated site.
